# Swiggy orange accent

16 November 2026. User request: use Swiggy orange for the case accent, with no
vermilion. The white base and corrected research-before-personas order stay.

The brand token is `#ff5200`. Links, selected stage/version/scenario controls,
focus outlines and the working-assumption boundary use orange. One light
`#fff5ee` Insights surface supplies a restrained tint. Text selection uses peach.
The header's Work state and keyboard skip link follow the same case palette.

Explanatory SVGs use orange for the open-ticket action, escalation-agent node,
refund totals and major-finding bar. Research diagram group fills use the light
tint. Original prototype images, video recordings and GIFs retain their colours.

Ordinary text remains ink. Orange against white is 3.25:1 and against the light
tint is 3.03:1, suitable for the accent indicators and large refund amounts.
Ink on orange is 4.74:1; action-node and skip-link labels therefore use ink.
The original labels and figures remain available alongside all coloured marks.

This change is scoped to the Swiggy case and its header. Asset hashes and the
SVG export scripts are updated; case content and reading order are unchanged.

Build, lint, TypeScript and whitespace checks pass. Rendered checks confirm orange
selected states/focus and a white base at 1440, 390 and 320px. The existing hero,
responsive/no-JavaScript, source-access and ten SVG artboard checks pass. Stage
labels maintain at least 5.25:1 contrast across the light orange band. Desktop and
phone compositions were visually inspected.
