# Portfolio Case Study Editorial

A reusable local Codex skill for refining Anuj Rai's project explanations, writing and visual presentation. Created 9 November 2026 from inspected references and the repository's standing requirements.

## Use

Invoke `$portfolio-case-study-editorial` and name the project and task. The repository's AGENTS.md also directs case-study content work to this skill.

Example:

> Use $portfolio-case-study-editorial to refine the Himalayan 450 case. Inspect the current page and original sources, remove repeated explanations, explain the supported decisions, and plan visuals using actual states. Preserve the existing portfolio rules and flag missing evidence.

## Portable installation

Copy the `portfolio-case-study-editorial` directory into `.agents/skills/` in the intended checkout. Read its SKILL.md when using a host that does not automatically discover repository skills. A new session may be needed for discovery; this archive does not install an account-wide skill or copy the project's original assets and briefs.

Anuj's repository already contains the installed directory and its AGENTS.md registration. No plugin or external connection is required to read the skill. Browsing is needed only when the actual task requires inspecting external references.
