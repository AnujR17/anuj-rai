## Composition changes

The opening has one original workspace in a straight laptop mockup. The complete
device and title fit in one fold. Floating evidence, backdrop rectangles, rotated
copies and the role card are removed. Insights uses individual readable details
rather than overlapping different interface states. The three recorded
interactions now have their explanation above a full-width window mockup;
no narrow alternating player or dark decision card remains.

The cost example is an open calculation and allocation, without a red canvas or
two decorative enclosing cards. Other SVG node boundaries describe actual
relationships and remain. Their typography, white fills, neutral lines and muted
chart values match the revised page. Source interface colours are preserved.

All eight GIF downloads use neutral application-window framing around the existing
recordings. MP4s, prototype source and original evidence images are unchanged.
The export script uses the same DM Sans font and proportionate 8:5 screen content.
The GIF frame uses square outer corners; the inline window has a small radius.

## Limits retained

The reference's metrics and persona biography are not imported into this case.
No internal Swiggy baseline or agent test is available. The existing assumptions,
source notes, unresolved review findings and proposed evaluation remain visible.
The user-confirmed purpose and contribution remain in `project-intent.md` and the
case introduction. This revision does not claim faster decisions or deployed use.
