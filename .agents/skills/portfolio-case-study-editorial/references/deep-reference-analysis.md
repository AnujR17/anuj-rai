## Sukhman: how the case system works

The common case structure starts with a product image and a short product explanation, then role, time and brief. The reading area splits into a persistent stage index and a larger story column. Small section labels organize dense material; enlarged figures and accent-colored phrases create a second reading path through the text. Research, synthesis, concept, design and evaluation are linked through repeated project-specific questions. The separate full cases expand the evidence. This is useful when an initial scan and a detailed review need different amounts of material.

The cost is density. A paragraph, a highlighted thesis and a concluding slogan can repeat the same point. Method inventories and prominent counts compete with actual decisions. Anuj should retain the causal connections and readable artifacts, using his existing type scale and stage navigation. A full case should add inspectable evidence, not simply larger headings and a second telling of the same story.
